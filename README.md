# PC-Project-system
Web-Based Inventory and Sales Management System with Integration of Serial number scanning and Automated quotation  for PC Project.

The **Web-Based Inventory and Sales Management System with Integrated Serial Number Scanning and Automated Quotation** is a capstone software project designed for **PC Project**, a local retail computer store.

The system was engineered to replace inefficient manual workflows—such as spreadsheet-based inventory tracking, paper-based supplier logbooks, Excel-created quotations, and disconnected Google Drive receipt records—with a unified, web-based platform
